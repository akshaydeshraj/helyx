# Review: OpenAI model provider against OpenCode (issue #7)

Three axes before commit: standards and spec (`/mattpocock-skills:code-review`) and the failure-path axis with throwaway tests under `.scratch/review/`. A simplify pass ran first; its transport finding (below) is the largest change.

## Fixed

- **Hand-rolled transport loop** (simplify, reuse): a `Stream.resource` with a bare `receive` re-implemented `Req.Response.Async`'s `Enumerable` and swallowed unrelated mailbox messages. Replaced with `Stream.flat_map` over the async body, which is selective on the ref, applies `receive_timeout` between chunks, and cancels on halt (verified against Req's docs and source).
- **Indexless tool call cross-wiring** (failure axis, reproduced): two tool call deltas without `"index"` merged into one call — the first call's id and name with the second call's arguments, a call the session would execute. The accumulator now implies an index: a delta with an id starts the next call, one without extends the last. The id and name are taken from the first delta that has them. Test added.
- **In-stream error object dropped** (failure axis, reproduced): a `data: {"error": ...}` chunk vanished and the turn failed as an opaque `:stream_ended`. Now `{:error, {:api_error, error}}`. Test added.
- **`req_options` escape hatch in provider opts** (spec, standards, simplify all flagged it): any caller could override `auth` or `url` through the opts keyword. The test seam moved to the `:req_options` application env of `:helyx_provider_openai`, set only in tests.
- **Partial usage map silently dropped** (spec): `usage/1` required both token fields; it now keeps whichever of `prompt_tokens` and `completion_tokens` is present.
- **Empty `data:` line failed the turn** (failure axis): now skipped.
- **No test for a connect-level transport error** (spec): added with `Req.Test.transport_error/2`.
- **Stale devlog** (standards, spec): it described the pre-review `Stream.resource` transport as shipped. Rewritten.
- **`@doc false` on public `stream/4` and `events/1`** (standards): both documented with specs.
- **"conversation" in the moduledoc** (standards): CONTEXT.md says session; fixed, and the moduledoc no longer promises a generic engine while hardcoding the OpenCode key and header.
- **Env var hygiene in tests** (standards): `OPENCODE_API_KEY` is now cleaned with `on_exit`. PR review (Greptile on #23) then flagged the module as `async: true` while it mutates the env and the `:req_options` app env; the case is now `async: false`, which matches the AGENTS.md shared-state rule.
- Smaller simplify fixes: `flush/1` as map-then-find over a `reduce_while` with quadratic appends; one-pass `:binary.split` line splitting; `wire_call/1` extraction; single binding for argument fragments; `if` for the optional system message; a shared `plug/1` test helper; `==` instead of `in` assertions. A second scoped pass then dropped the named `Req.Test` stubs for bare function plugs and pinned the blank `data:` line in the boundary test.

- **Thinking dropped from assistant messages** (PR review on #23, P1): the encoder stripped `Thinking` blocks, but Kimi's thinking models require the loop's `reasoning_content` back on the assistant message during multi-step tool calls, so continuation after a tool result degraded or broke. Assistant messages now carry their concatenated thinking as `reasoning_content`; models that do not think produce no thinking blocks, so their requests are unchanged. Request test added. If a model family ever rejects the field on input, that becomes a per-model knob then.

## Skipped, with reasons

- **Malformed chunk shapes raise instead of returning error events** (failure axis): a `choices` map or non-iodata arguments crashes the turn Task, which core already defines as a failed turn (`{:task_exit, reason}`). Consistent enough; guards would grow the parser for shapes no gateway sends.
- **Optional `x-opencode-session` header**: the session always passes `session_id`, so the header always goes out on real turns. The nil branch only covers direct calls, where sending nothing is more honest than crashing.
- **`Helyx.Message.tool_calls/1` helper** (reuse): the extraction comprehension has three call sites across the repo; extract at the fourth.
- **Endpoint config as data instead of nested modules** (altitude): `Provider.find/2` needs one module per id; two 11-line modules do not earn a registry of records.
- **Per-frame event list allocation** (efficiency): readable as is; trivial for the BEAM.
- **Turn timeout owned by the session** (altitude): agreed in principle, deferred until a second real provider exists.
- **Structs for the parser accumulator** (standards): local, short-lived, single-module maps.
- **Manual IEx run against a live gateway** (spec): blocked, no `OPENCODE_API_KEY` on this machine; commands are in the devlog.
